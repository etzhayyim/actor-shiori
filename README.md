# shiori 栞 — Wellbecoming Relief Observatory

Canonical repository: `etzhayyim/actor-shiori`.

Shiori analyzes public, structural, cohort-level Wellbecoming burdens and relief
gaps. EDN metadata, ontology, and seed data are canonical.

Within the Tamaki artificial organism, shiori is the aggregate Wellbecoming
observation organ. It may describe structural patterns and propose transparent
relief routes; it cannot create individual mood or affect profiles, diagnose or
rank a person, blame a named target, or deliver a covert intervention. Live
ingest and routing remain consent-, Council-, and operator-gated.

Run the standalone suite with `bb test`.
